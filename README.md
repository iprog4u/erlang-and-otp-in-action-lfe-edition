# erlang-and-otp-in-action-lfe-edition #
========================================

This is a translation of the source code from an excellent book which I found deeply helpful in learning the OTP framework,  "Erlang and OTP In Action" ([1]https://github.com/erlware/Erlang-and-OTP-in-Action-Source) in to Lisp Flavoured Erlang (https://lfe.io)


## Credit where it is due
-------------------------

First things first.  The code contained within this repository is merely a shallow translation of the code in link [1] above into Lisp Flavoured Erlang, a language which I enjoy.  Martin Logan, Eric Merritt, Richard Carlsson wrote the Erlang code for this book 15 years ago and are responsible for me "getting" OTP.  I highly recommend this book for anyone looking to explore Erlang/OTP and its immense power.  Great big thanks to all three for opening up new possibilities for me to explore.


## Why?
-------

Because I enjoy working with Erlang/OTP and I find the framework to be wildly powerful.  I also have a burning passion for Lisp and Robert Virding is a genius for not only helping create the Erlang language in the first place but further developing a proper Lisp-2 on top of the BEAM.  Lisp Flavoured Erlang (yes, I am sticking to the European spelling) takes all of the power of Erlang/OTP and combines it with all of the power of Lisp.  This opens up new possibilities for developers to explore and I encourage all to learn even just a little bit of Lisp.  Doing so has often been reported to improve the way one thinks in their language of choice so what have you got to lose?  Try it...you might like it.
